# Chrono Trigger Vortex Effect

https://user-images.githubusercontent.com/901936/209407117-24c1660b-17b9-4fd3-a830-59c571b27b7e.mp4

A reimagined effect of Chrono Trigger's time travel portal made in GLSL. 

You can play around with the [demo](https://www.shadertoy.com/view/dlf3WM)



## Summary

A fork of [raphaklaus/chrono-trigger-portal-shader](https://github.com/raphaklaus/chrono-trigger-portal-shader). GLSL shaders that recreate Chrono Trigger's time-portal vortex.

## What's inside

`vortex.frag`, `spiral.frag` and `waves.frag` (the shaders), `index.html` and `index.js` (the viewer), and `vortex-demo.mp4`.

## How to view or run it

Serve the folder (for example `python3 -m http.server`) and open `index.html`, or try the Shadertoy demo.
